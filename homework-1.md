# Домашнее задание №1 — Telegram-бот с локальной LLM

## 🎯 Цель

Разработать Telegram-бота, который работает как простой AI-чат, используя локальную языковую модель (LLM).

---

## 🧠 Описание задачи

Необходимо создать Telegram-бота, который:

- принимает текстовые сообщения от пользователя
- передаёт их в локальную LLM
- возвращает сгенерированный ответ обратно в Telegram

> ❗ **Важно:** каждое сообщение должно обрабатываться независимо, **без хранения истории диалога**.

---

## ⚙️ Технические требования

### 1. LLM (обязательно локально)

Использовать одну из следующих систем:

- [Ollama](https://ollama.com/)
- [vLLM](https://github.com/vllm-project/vllm)
- [Lemonade](https://github.com/lemonade-hq/lemonade)
- [MLX](https://github.com/ml-explore/mlx)

Рекомендуемые модели:

- `qwen3:0.6b`
- `qwen3.5:0.5b`

### 2. Язык программирования

На выбор:

- Python
- JavaScript / TypeScript

### 3. Telegram API

Использовать Telegram Bot API через **polling** (НЕ webhook).

### 4. Архитектура

Минимальная архитектура:

```
Telegram → Bot → LLM → Bot → Telegram
```

Без базы данных и без хранения состояния.

---

## 🤖 Особое требование (ключевое)

Код бота должен быть **сгенерирован с помощью LLM** (например, ChatGPT, локальная модель, Copilot и т.д.).

**Разрешается:**
- генерировать код частями
- дорабатывать и исправлять

**Запрещено:**
- писать весь код вручную с нуля

---

## 📦 Функциональные требования

Бот должен:

- ✅ отвечать на любые текстовые сообщения
- ✅ корректно обрабатывать ошибки (например, если LLM недоступна)
- ✅ работать стабильно при нескольких запросах подряд

---

## 🚫 Ограничения

- ❌ Без хранения истории диалога
- ❌ Без использования облачных LLM (OpenAI, Anthropic и т.д.)
- ❌ Без базы данных

## 📋 Регистрация бота в Telegram

Telegram-боты создаются с помощью специального бота **@BotFather**. Через него можно управлять данными бота, добавить описание, аватар и т.д.

**Шаги создания бота:**

1. Откройте в Telegram бота [@BotFather](https://t.me/BotFather).
2. Напишите `/newbot`.
3. Придумайте и напишите **название** бота. Оно будет отображаться в контактах и чатах. Например: «Hello, bot».
4. Придумайте и напишите **юзернейм**. Он используется для упоминания бота и в ссылках. Юзернейм должен быть на латинице и обязательно заканчиваться на `bot`. Например: `botmother_hello_bot`.

**Подключение токена:**

1. Снова откройте @BotFather.
2. Скопируйте токен бота.
3. Используйте токен в вашем коде.
