# Telegram-бот с локальной LLM

Telegram-бот, который принимает текстовые сообщения от пользователей и отвечает на них, используя языковую модель, запущенную локально через Ollama.

---

## Стек технологий

- **Python 3.11+**
- **python-telegram-bot 21.3** — работа с Telegram Bot API
- **Ollama + qwen3:0.6b** — локальный запуск LLM без облачных сервисов
- **python-dotenv** — управление переменными окружения

---

## Установка и запуск

```bash
# 1. Клонировать репозиторий
git clone <repo-url>
cd homework-1-bot

# 2. Создать и активировать виртуальное окружение
python -m venv venv
source venv/bin/activate        # macOS/Linux
# venv\Scripts\activate         # Windows

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Настроить окружение
cp .env.example .env
# Отредактируйте .env — вставьте токен Telegram-бота

# 5. Установить и запустить Ollama
# https://ollama.com/
ollama pull qwen3:0.6b
ollama serve

# 6. Запустить бота
python bot.py
```

---

## Переменные окружения

Перед запуском скопируйте `.env.example` в `.env` и заполните значения:

| Переменная | Описание | Пример значения |
|---|---|---|
| `TELEGRAM_TOKEN` | Токен бота от @BotFather | `123456:ABC-DEF...` |
| `OLLAMA_BASE_URL` | Адрес Ollama API | `http://localhost:11434` |
| `OLLAMA_MODEL` | Название модели | `qwen3:0.6b` |
| `SYSTEM_PROMPT` | Системный промпт (опционально) | `You are a helpful assistant` |

> **Важно:** никогда не коммитьте `.env` с реальным токеном. Файл `.env` добавлен в `.gitignore`.

## Использованная LLM и подход к генерации кода

Проект выполнен как домашнее задание по курсу работы с LLM. Весь код генерировался с помощью языковых моделей по структурированным промптам из папки `tasks/`.

Каждая задача оформлена в виде отдельного файла (`tasks/01-*.md`, `tasks/02-*.md`, ...) и содержит три обязательных раздела:

- **Context** — что уже сделано и какова структура проекта
- **Requirements** — что именно нужно реализовать
- **Acceptance criteria** — список критериев, по которым проверяется результат

Такой подход обеспечивает воспроизводимость: передавая задачу с полным контекстом и чёткими критериями, можно получить корректный и предсказуемый результат от LLM вместо размытых инструкций в свободной форме.

В качестве локальной модели используется **qwen3:0.6b** через **Ollama** — лёгкая модель, которая запускается без GPU и подходит для разработки и тестирования на обычном ноутбуке.

## Архитектура

```
Пользователь → Telegram → bot.py → ollama_client.py → Ollama (локально) → ответ обратно
```

- `bot.py` — точка входа, обрабатывает команды `/start` и текстовые сообщения, ведёт логирование в `bot.log`
- `ollama_client.py` — клиент для обращения к Ollama API
- `config.py` — загрузка конфигурации из переменных окружения
