# Task 02: Ollama LLM Client

## Context
Скелет проекта уже создан (Task 01). Существуют файлы:
- `config.py` — экспортирует `OLLAMA_BASE_URL` и `OLLAMA_MODEL`
- `ollama_client.py` — пустая заглушка, которую нужно заполнить
- `requirements.txt` — содержит библиотеку `ollama==0.2.1`

Локальная LLM запущена через [Ollama](https://ollama.com/) на `http://localhost:11434`.
Используемая модель: `qwen3:0.6b` (или значение из `OLLAMA_MODEL`).

## Goal
Реализовать модуль `ollama_client.py` — единственную точку взаимодействия с локальной LLM.

## Requirements

1. Использовать библиотеку `ollama` (не `httpx` или `requests` напрямую).

2. Реализовать асинхронную функцию:
   ```python
   async def ask_llm(user_message: str) -> str:
   ```
   Функция должна:
   - Принимать текст пользователя как строку
   - Отправлять его в Ollama как единственное сообщение (роль `user`)
   - Возвращать текстовый ответ модели как строку
   - **Не хранить историю** — каждый вызов независим

3. Обработка ошибок внутри функции:
   - Если Ollama недоступна (`ConnectionError`, `Exception`) — поймать исключение
   - Вернуть понятное сообщение об ошибке на русском языке, например:
     `"⚠️ Не удалось получить ответ от LLM. Убедитесь, что Ollama запущена."`
   - **Не пробрасывать исключение выше** — бот должен оставаться живым

4. Использовать `OLLAMA_BASE_URL` и `OLLAMA_MODEL` из `config.py`.

5. Добавить в конец файла блок `if __name__ == "__main__"` для ручного тестирования:
   ```python
   if __name__ == "__main__":
       import asyncio
       response = asyncio.run(ask_llm("Привет! Как дела?"))
       print(response)
   ```

## Expected output

Файл `ollama_client.py` с реализованной функцией `ask_llm`.

## Acceptance criteria
- [ ] Функция `ask_llm` является асинхронной (`async def`)
- [ ] Каждый вызов отправляет только одно сообщение (без истории)
- [ ] При недоступности Ollama функция возвращает строку с ошибкой, а не бросает исключение
- [ ] Можно запустить `python ollama_client.py` и получить ответ от модели
- [ ] Используются константы из `config.py`, а не захардкоженные строки
